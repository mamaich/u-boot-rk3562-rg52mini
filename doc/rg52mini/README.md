# U-Boot для AISLPC RG52 Mini

Форк дерева U-Boot от Rockchip (2017.09, ветка `next-dev`) с поддержкой
RK3562. Цель — свой загрузчик для карманной консоли RG52 Mini, где заводской
работает наполовину.

## Зачем это понадобилось

В устройстве два загрузчика, и оба неполноценны:

| | выключение | включение с кабелем | зарядка |
|---|---|---|---|
| авторский, на карте | работает | **виснет** | работает |
| с внутренней памяти | **ломается** | работает | ? |

«Виснет» означает режим ожидания зарядки: устройство светит лампочкой, экран
тёмный, кнопка не выводит. «Ломается выключение» — по команде «выключить»
PMIC снимает питание и тут же включает плату обратно.

Разбор причин: [01-разбор.md](01-разбор.md).
Сборка: [02-сборка.md](02-сборка.md). Планы: [03-планы.md](03-планы.md).

## Что уже сделано

* Заводской загрузчик разобран по частям, версии и блобы опознаны.
* Установлено, что заводская сборка с внутренней памяти — это практически
  нетронутый `rk3562_defconfig`: её дерево **побайтно совпадает** с тем, что
  собирается из публичных исходников.
* Добавлено дерево нашей платы `rk3562-rg52mini`: PMIC RK817 со всеми
  регуляторами, счётчиком заряда, зарядным устройством, кнопкой питания,
  светодиодом и режимом зарядки. По составу узлов совпадает с авторским.
* Консоль переведена на `uart0` (он выведен на площадки платы) и на 115200.
