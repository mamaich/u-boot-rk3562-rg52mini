# U-Boot для карманной консоли AISLPC RG52 Mini

Это форк дерева U-Boot от Rockchip (2017.09, ветка `next-dev`), доработанный
под карманную консоль **AISLPC RG52 Mini** на RK3562. Заводские загрузчики
этого устройства работают наполовину: один не выключает плату, другой не
выходит из режима зарядки по кнопке, и ни один не показывает на экране
ничего до старта системы.

Здесь это исправлено: работают выключение, выход из зарядки, логотип при
включении, анимация зарядки и светодиод, загорающийся сразу после подачи
питания. Консоль выведена на площадки `uart0` платы.
